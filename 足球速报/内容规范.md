# 足球速报 · 内容规范（App 与日报共用标准）

> 每天生成的日报 md 与「足球速报」App 排版共用这一套板块标准。

## 一、标准板块（按此顺序）

### 一、重点场次

- 逐场展开：比分、进球全记录（含助攻+过程描述）、其他重大事件、赛前赛后采访、本场来源
- 详见现有格式，保持不变

### 二、其他完赛比分

- 本窗口内其余比赛，一行一场，带联赛、比分、备注

### 三、球星动态

- 头部球星（C罗、梅西、姆巴佩、哈兰德、贝林厄姆等）的最新动向
- 覆盖：训练 / 伤病 / 回归 / 社媒发声 / 里程碑纪录 / 场外新闻
- 每条写清「他做了什么」+「有什么含义」
- 格式：`- **人名**（俱乐部/国家队）**标签**：内容`

### 四、足坛动态

- 奖项评选（金球奖 / 金童奖 / 最佳教练等）
- 教练席变动（下课 / 上任 / 续约）
- 俱乐部经营、伤停潮、更衣室消息
- 青训、国家队征召、退役与告别
- 格式：`- **标签**：内容`

### 五、转会速递

- 已完成的转会 + 传闻中的交易
- 写清「哪家俱乐部 + 谁 + 什么状态（已官宣 / 传闻 / 谈判中）」
- 格式：`- **球员名**：内容`

### 六、焦点前瞻（分版块，本节是重点）

按比赛性质分成 4 个版块，每个版块用 `###` 起头（顺序固定）：

| 版块         | 收什么                    | 条数    |
| ---------- | ---------------------- | ----- |
| 6.1 焦点之战   | 未来几天最值得看的比赛，**写最详细**   | 2–3 场 |
| 6.2 联赛关键战  | 争冠 / 争四 / 保级、直接影响排名的比赛 | 2–4 场 |
| 6.3 欧战与国家队 | 欧冠、欧联、欧协联、世预赛、欧国联等     | 2–4 场 |
| 6.4 球星看点   | 复出、里程碑、转会后首秀、宿敌/师徒对决   | 1–3 条 |

每条预告的固定格式（**焦点之战必须写全 4 个字段，其余版块至少写「看点」**）：

```markdown
### 6.1 焦点之战
- **10-08 03:00 · 欧冠联赛阶段**：皇家马德里 vs 曼城
  - **看点**：为什么值得看，1–2 句
  - **近况**：双方近期战绩 / 积分排名 / 主客场状态
  - **交锋**：历史交手战绩（近 N 次 X 胜 X 平 X 负）
  - **伤停**：关键球员缺阵或复出
```

要求：

- 时间一律写**北京时间**，格式 `MM-DD HH:MM`
- 赛事名写完整（如「英超第 8 轮」「欧冠联赛阶段第 2 轮」）
- 对阵用 `主队 vs 客队`
- **不预测比分、不预测胜负**，只陈述事实与看点
- 查不到就少写或不写，绝不凑数

### 七、来源附录

- 分组列出各板块引用来源

## 二、写作要求

- **语言**：白话、简洁，不堆砌数据
- **每条结构**：发生了什么 → 为什么值得关注
- **不编造**：查不到就写「暂无」，绝不脑补
- **去重**：与历史日报对比，旧闻不重复

## 四、后端数据结构（add_report.py 输出）

```js
{
  date, weekday, title, summary, tags,
  coverage: [{label, text}],
  matches:  [{league, home, away, scoreHome, scoreAway, venue,
              goals:[{time, team, scorer, assistType, assist, desc}],
              events:[{label, text}], pre:[], post:[], sources:[]}],
  others:   [{league, home, scoreHome, scoreAway, away, note}],
  stars:    [{name, tag, text}],     // 球星动态
  world:    [{name, tag, text}],     // 足坛动态
  transfer: [{name, tag, text}],     // 转会速递
  schedule: [{name, tag, text}],     // 赛程预告（旧格式，向后兼容）
  preview:  [{group, items:[{name, tag, text,
                             detail:[{name, tag, text}]}]}],  // 焦点前瞻（分版块，新）
  refs:     [{group, links:[{name, url}]}],
  md
}
```

`preview` 说明：

- `group` = 版块名（如「6.1 焦点之战」）
- `items[].name` = `时间 · 赛事`；`items[].text` = 对阵
- `items[].detail[]` = 看点 / 近况 / 交锋 / 伤停，`name` 是字段标签

未提供新板块时，App 自动隐藏对应区域（向后兼容旧数据）。  
有 `preview` 时按版块渲染；没有则退回用 `schedule` 的扁平列表。
